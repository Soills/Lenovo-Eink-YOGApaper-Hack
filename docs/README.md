# 文档索引 / Docs index

这两台机器是同一块硬件板（Louvre_3566_4G）的两个市场版本，固件不互通。文档按型号分开。

The two machines share the same hardware board (Louvre_3566_4G) but are different market SKUs with incompatible firmware. Docs are split by model.

- [YOGA Paper (SP101FU)](SP101FU-YOGA-Paper/) — 逆向和 adb 路线（Settings 焊死、recovery-in-boot 等）
- [启天 Smart Paper (SP523FC)](SP523FC-QiTian/) — root、开 adb、解锁设置、刷机流程

中文在 README.md，英文在 README.en.md。
